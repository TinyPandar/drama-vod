管理控制台改版：整体风格预览

这一版只出三个核心页面，用来确认整体风格。它们是静态页面，不连接任何接口，按钮不执行操作。 每个页面顶部有一条深色「预览条」，可以切换示例状态；预览条本身不属于产品界面。

三个核心页面

登录页

不套后台外壳。左边讲清「管理登录」和「租户 Key」两种身份，右边是登录表单。

默认登录中口令错误登录已过期

租户与 Key

后台外壳 + 租户列表；进入租户后是 Key 管理，新 Key 明文只出现一次并可「在本标签页使用」。

租户列表租户详情 · Key新 Key 明文加载中空列表加载失败

资产列表

租户端页面。没选 Key 或 Key 失效时给整页引导，而不是只显示 401。

正常未选用 KeyKey 已失效上传中中断可续传加载中空列表配额用尽

配色建议

浅色后台。靛蓝是主色，同时代表「管理登录」；青绿只代表「租户 Key」。两种身份在侧栏分组、右上角和引导页里始终用这两种颜色加文字区分。

加载 / 空 / 错误

加载中：保留表头，用骨架条占位，不整页转圈。

空：图标 + 一句现状 + 一句下一步。错误：页面上方提示条说明原因并给「重试」，列表区保持稳定。三者都在卡片内同一位置出现。
