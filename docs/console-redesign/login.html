视频云控制台

先登录管理端，再选一把租户 Key

控制台里有两种身份，各管一部分页面，互相不能代替。登录后页面右上角会一直显示这两项的当前状态。

管理登录 本页登录的就是它

用管理员用户名和口令登录。可以进入「租户与 Key」「模板」：建租户、调配额、新建或撤销 Key。

租户 Key 登录后再选用

某个租户的 API Key。「资产」「任务」「Webhook」「用量与配额」只认它，管理登录进不去这些页面。Key 只保存在当前浏览器标签页。

① 管理登录→ ② 建租户、新建 Key→ ③ 点「在本标签页使用」→ 进入资产等租户页
